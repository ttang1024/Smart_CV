# SmartCV — Frontend

This directory contains the React 19 + TypeScript + Vite frontend.

For full documentation — setup, architecture, deployment, and contributing — see the **[root README](../README.md)**.

## Quick start

```bash
npm install
npm run dev      # dev server at http://localhost:5173
npm run build    # production build → ../SmartCV.API/wwwroot
npm run lint     # ESLint
```

The dev server proxies `/api` requests to `http://localhost:5000` (the .NET backend).
